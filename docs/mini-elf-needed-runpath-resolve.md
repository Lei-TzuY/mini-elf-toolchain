# mini-elf-needed-runpath-resolve

`mini-elf-needed-runpath-resolve <symbol> <root-et-dyn> <fallback-library-dir>` builds a deterministic breadth-first `DT_NEEDED` closure and resolves the requested external definition through the existing mixed GNU/SysV dynamic-hash resolver.

For each image, checked legacy `DT_RPATH` entries participate in dependency search and are inherited by descendants, matching the important loader distinction that legacy RPATH can affect indirect dependencies. A descendant's own `DT_RPATH` entries are searched before inherited ancestor entries and then carried forward. Checked `DT_RUNPATH` remains local to the image that declares it: inherited ancestor RPATH entries are consulted before that image's RUNPATH, while the RUNPATH entries themselves are not propagated to grandchildren. If an image contains both tags, `DT_RUNPATH` takes precedence over that image's own `DT_RPATH`.

Both path tags use the same bounded expansion rules. `$ORIGIN` / `${ORIGIN}` and `$ORIGIN/<safe-relative-path>` / `${ORIGIN}/<safe-relative-path>` are accepted, entries preserve colon-separated order, and lookup remains confined beneath the declaring image's containing directory. Within an ORIGIN-anchored safe relative path, the x86-64 ELF64 loader tokens `$LIB` / `${LIB}` and `$PLATFORM` / `${PLATFORM}` are accepted only as complete path components. `$LIB` expands deterministically to `lib64`, while `$PLATFORM` expands deterministically to `x86_64`, so forms such as `$ORIGIN/$LIB` and `${ORIGIN}/${PLATFORM}/plugins` are supported without opening unanchored search paths. Empty entries, absolute/unanchored entries, parent traversal, embedded or otherwise unsupported dynamic-token placements, duplicate `DT_RUNPATH` or `DT_RPATH`, malformed dynamic strings, missing dependencies, and non-file candidates fail closed before stdout is emitted. Duplicate effective search directories are collapsed while preserving first occurrence.

A `DT_NEEDED` name that contains `/` is treated as a bounded direct dependency pathname instead of a search name. This slice accepts only `$ORIGIN` / `${ORIGIN}`-anchored direct paths, reusing the same safe-relative-component validation and x86-64 `$LIB` / `$PLATFORM` expansion as RUNPATH/RPATH. Direct dependencies bypass inherited RPATH, local RUNPATH, and the fallback directory; the expanded pathname itself must name a regular file. Unanchored, absolute, parent-traversing, or unsupported-token direct names fail closed before any resolver output is emitted.

The dependency scope remains breadth-first: the root is searched first, then direct dependencies in `DT_NEEDED` order, followed by newly discovered transitive dependencies. Repeated dependency names are collapsed after first discovery.

GNU binutils-backed regression coverage emits legacy RPATH with `ld --disable-new-dtags --rpath=...` and RUNPATH with `ld --enable-new-dtags --rpath=...`, then confirms the tags with `readelf -dW`. The focused inheritance fixture proves that a root RPATH can resolve a grandchild through an intermediate image with no path tag, while the otherwise-equivalent root RUNPATH fixture fails closed because RUNPATH is intentionally not inherited. Additional coverage preserves `${ORIGIN}/${LIB}/...` and `${ORIGIN}/${PLATFORM}/...` literally in emitted dynamic strings and verifies that the resolver reaches the corresponding `lib64` and `x86_64` directories, while embedded token text such as `pre$LIB` or `pre$PLATFORM` is rejected atomically. Direct-path coverage uses GNU `ld -soname` to emit `$ORIGIN/$LIB/$PLATFORM/libleaf.so` as a literal `DT_NEEDED` name, verifies it with `readelf -dW`, and proves that resolution succeeds without consulting RUNPATH/RPATH or fallback search; escape and unsupported-token variants remain atomic failures.

This slice intentionally does not implement absolute or cwd-relative direct `DT_NEEDED` paths, unanchored relative RUNPATH/RPATH entries, `LD_LIBRARY_PATH`, ld.so cache/default directory search, arbitrary dynamic-string substitutions, symbol version matching, IFUNC execution, or relocation application.
