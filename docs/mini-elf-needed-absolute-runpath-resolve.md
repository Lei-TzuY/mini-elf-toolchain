# `mini-elf-needed-absolute-runpath-resolve`

`mini-elf-needed-absolute-runpath-resolve [--ld-library-path <dir[:dir...]>] <symbol> <root-et-dyn> <fallback-library-dir>` extends the checked RUNPATH/RPATH dependency resolver with bounded loader-compatible support for ordinary absolute directory entries and normalized relative non-token directory entries in `DT_RUNPATH` and `DT_RPATH`.

Absolute entries preserve the existing search semantics. Relative non-token entries are resolved against the process current working directory, matching the loader-visible meaning of an unanchored relative search directory rather than rebasing it beneath the declaring shared object's directory. `DT_RUNPATH` remains local to the image that declares it, while legacy `DT_RPATH` remains inheritable by descendants. Explicit loader-path directories retain their existing precedence, SONAME identity de-duplication and breadth-first dependency scope are unchanged, and the final symbol lookup still uses the existing checked GNU/SysV dynamic-hash resolver.

The slice deliberately remains narrower than a host dynamic loader. Absolute entries must be normalized paths containing only the root plus normal components. Relative non-token entries must contain one or more normal components and may not contain empty components, `.` or `..`. Dynamic tokens embedded in absolute or ordinary relative entries are rejected; the previously supported `$ORIGIN`, `$LIB`, and `$PLATFORM` anchored forms remain available through the checked token-expansion path. Ambient `LD_LIBRARY_PATH`, loader cache/sysroot semantics, empty RUNPATH/RPATH components, and general dynamic-loader emulation remain outside this bounded capability.

Focused integration uses GNU `as` / `ld` to construct real ELF64 shared objects and GNU `readelf -dW` to confirm emitted `RUNPATH` / `RPATH` metadata. Coverage proves direct absolute RUNPATH lookup, inherited absolute RPATH lookup, relative RUNPATH lookup against an explicitly selected process cwd, inherited relative RPATH lookup across a transitive dependency, and fail-closed rejection of non-normalized absolute and relative entries with atomic stdout.
