# Bounded dynamic R_X86_64_PC32 validation

This branch implements a focused ELF64 x86-64 validator for `R_X86_64_PC32` entries in `DT_RELA`, with GNU `readelf` differential coverage and malformed-input checks.

When SysV `DT_HASH` is absent, the validator also accepts GNU-hash-only images and derives the dynamic-symbol upper bound from checked `DT_GNU_HASH` bucket, Bloom, and chain metadata. SysV `DT_HASH` remains authoritative when present. The regression suite builds a real `ld --hash-style=gnu` shared object, verifies it with GNU `readelf`, and rejects malformed GNU-hash Bloom metadata.
